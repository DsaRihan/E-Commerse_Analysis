# E-commerce Sales Analysis 📊

## 📁 Project Overview

The notebook performs the following tasks:

- Data exploration and descriptive statistics
- Date column conversion and extraction
- Creation of new time-based columns: Order Month, Year, Day
- Monthly sales trend analysis
- Visual exploration of sales over time

## 📂 Dataset Requirements

Make sure your dataset contains at least the following columns:

- `Order Date`: for generating time-based features
- `Sales`: for revenue analysis
- `Profit`: optional but recommended for profitability insights

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 How to Use

1. Clone this repository or download the notebook.
2. Place your dataset in the appropriate directory.
3. Open the notebook with Jupyter Notebook or JupyterLab.
4. Run the cells sequentially to generate visualizations and analytics.

## 🔍 Key Insights

- Monthly sales and profit trends
- Impact of seasonal patterns on order volume
- Potential correlation between date features and revenue
